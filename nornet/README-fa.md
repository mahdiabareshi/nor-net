# ⚡ نورنت — سایت فروش کانفیگ (نسخه رزومه / دمو)

پروژه تمام‌فرانت‌اند و بک‌اند با **Next.js (App Router) + TypeScript + Prisma (SQLite)**.
مسیر کامل فروش: ثبت‌نام ← شارژ کیف پول با کارت‌به‌کارت و تأیید رسید توسط ادمین ← خرید کانفیگ ← تحویل لینک اشتراک.

> **نسخهٔ رزومه:** پنل پاسارگارد عمداً غیرفعال است (`PANEL_ENABLED=false`)؛ خرید شبیه‌سازی می‌شود و لینک اشتراکِ نمونه (`/api/demo-sub/...`) تحویل داده می‌شود — بدون هیچ اتصال واقعی. کد اتصال به پنل در `src/lib/panel.ts` کامل موجود است و با سه متغیر محیطی فعال می‌شود.

## امکانات

- **صفحهٔ خانه برای مهمان** (پیش‌فرض باز می‌شود، نه صفحه ورود) + دکمه «ورود / ثبت‌نام» در نوار بالا
- پنل حساب کاربری با تب‌های: خانه / کیف پول / خرید کانفیگ / سفارش‌های من / (+ ادمین: رسیدها، تنظیمات)
- **شارژ کیف پول دستی:** ادمین شماره کارت، نام صاحب کارت و بانک را در تنظیمات وارد می‌کند (در نسخه رزومه خالی است)؛ کاربر مبلغ + عکس رسید را می‌فرستد؛ ادمین تأیید/رد می‌کند (رد با یادداشت دلیل)
- **خرید کانفیگ:** بسته حجمی (۱–۳ ماه) و نامحدود (۱/۲/۳/۶/۱۲ ماه)، تعداد دستگاه (تا ۳ رایگان، هر دستگاه اضافه ۱٬۰۰۰ تومان)، قیمت‌گذاری لحظه‌ای
- **ساخت خودکار کانفیگ:** در حالت واقعی با API پنل پاسارگارد (PasarGuard v5) و در حالت دمو شبیه‌سازی با لینک اشتراک نمونه
- اتصال اتمی به کیف پول (برداشت شرطی)، بازگشت خودکار مبلغ در خطای پنل، گردش کیف پول
- آپلود و نمایش امن عکس رسید (فقط برای ادمین)
- رابط فارسی RTL، تم تیره بنفش، ریسپانسیو کامل (موبایل/دسکتاپ)

## اجرا

```bash
# ۱) نصب وابستگی‌ها
npm install        # یا bun install

# ۲) آماده‌سازی دیتابیس (فایل SQLite ساخته می‌شود)
cp .env.example .env
npx prisma db push
npx prisma generate

# ۳) ساخت حساب ادمین (پیش‌فرض: admin / admin123)
node scripts/seed-admin.js

# ۴) اجرا
npm run dev        # http://localhost:3000
```

ورود ادمین: `admin` / `admin123` — برای محیط واقعی رمز را عوض کنید.

## تست خودکار (Playwright)

```bash
node scripts/e2e_wallet.js   # ۳۹ تست: مهمان/ثبت‌نام/رسید/تأیید/رد/خرید دمو/موجودی ناکافی
```

## فعال‌سازی اتصال واقعی به پنل (بعداً)

در `.env`:

```
PANEL_ENABLED=true
PANEL_URL=https://آدرس-پنل-شما
PANEL_API_KEY=pg_key_...
PANEL_GROUP_ID=1
```

پس از ری‌استارت سرور، خرید کانفیگ به‌جای شبیه‌سازی، کاربر را واقعاً در پنل می‌سازد و لینک اشتراک اصلی را تحویل می‌دهد. وضعیت اتصال در «تنظیمات (ادمین) → وضعیت سیستم» دیده می‌شود.
